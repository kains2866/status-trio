用户选择：保留宽功率色带，修好与卡片接缝。纳入电池详情、ABC a/A，并修复简/繁和浅色滑块；保持 #269 的布局和侧向子面板。

## Approaches
- 采用：宽色带与卡片下方搭接，共用边界裁切，消除接缝且保留流量比例。
- 未采用：完整圆角卡片与细曲线，用户明确选择宽色带。
- 滑块保持原生细轨道及输入逻辑；去掉深色文字色强制填充，核对系统原生材质。不得退回带设备名的粗胶囊。

## Scope
- 选择性移植上游电池健康、容量、运行时长及高功率状态展示；未知值不伪造。
- 输入法保留简/繁显式文字，并移植 ABC 修饰键大小写观察；菜单栏和 Dock 共源。
- 多显示器亮度后端、VPN、其他性能批次与充电控制行为不在此次范围。
- 兼容 macOS 13；材质 API 按可用版本使用，不为旧系统伪造玻璃效果。
- 回归覆盖系统图片与文字优先级、大小写组合、宽色带连接和无连接卡片、浅深色与禁用滑块。
