# 应用音量混音器（开发中）

先在「设置 → 音频 → 应用音量」开启「启用应用混音」。该开关默认关闭并持久保存；关闭时标题区域没有悬浮子面板。开启后，在状态面板的「音量」标题或其右边空白区域停留，打开应用音量侧向子面板；点击标题也可打开。齿轮继续打开系统设置。麦克风标题打开正在使用音频输入的应用列表，此列表不修改各应用的录音。

开启设置后，可直接调整子面板中某个应用的音量或静音。首次实际调整时，macOS 可能请求系统音频录制权限。悬浮和打开列表本身不捕获音频。音频只在内存里调节，不保存或上传。

列表按应用分组，例如 Chrome 音频辅助进程显示为 Google Chrome；不会将同一浏览器的网页标签伪装成独立应用。图标、名称中间省略、名称悬浮展开、静音按钮与原有滑块布局保持一致。

音量范围为 0–100%。关闭面板后混音继续生效；同一应用暂停后再播放保留音量。应用退出或输出路径、采样格式发生变化时释放处理。将某应用恢复为 100% 且取消静音时恢复原生播放。「全部重置」将各应用恢复为 100% 并取消静音，保持功能开启；只有设置开关可以关闭功能。清理失败时保留重试入口（关闭功能后，标题行也会保留可点击的重试清理按钮，但不会恢复悬浮入口）；退出 Status Trio 也会执行清理。

首版需要 macOS 14.2 或更高版本；软件本身仍保持 macOS 13 部署下限。当前后端要求单一、支持的 Float32 立体声输出端点，且物理输出端点不能暴露输入流；双向共享端点、聚合设备、多路径及其他格式会拒绝启用，不强制改变系统输出设备。这项限制按实际端点判断，不能仅按耳机品牌推断支持情况。

人工验收时请先退出其他应用音量混音器（例如 FineTune），避免两个工具同时接管同一音频流。用浏览器视频和另一个播放应用检查独立调节、静音、暂停恢复、输出切换及重置；权限拒绝和 AirPods 连接变化也需要实机验证。自动测试使用模拟 HAL 和合成音频缓冲区，不证明真实设备音效、延迟或权限表现。
