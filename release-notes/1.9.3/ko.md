# 개인 버전 %VERSION% (빌드 %BUILD%)

### 개인 패널 개선

- 화면 밝기, 출력 음량, 마이크 게인에 얇은 기본 슬라이더를 사용하고 장치 행을 정렬했습니다.
- 지원되는 장치의 음량과 음소거를 개별적으로 제어합니다. 왼쪽 장치 아이콘을 클릭하면 시스템 출력 또는 입력을 선택합니다.
- 긴 장치 이름은 마우스를 올리면 애니메이션이 있는 떠 있는 영역에 전체 표시됩니다. 장치가 네 개 이상이면 측면 패널을 사용합니다.
- 마우스를 올려 여는 측면 패널과 중립적인 회색 강조 표시를 통일했습니다. Wi-Fi 세부 정보는 요청하기 전까지 접힌 상태로 유지됩니다.
- 마이크를 전환해도 장치 순서를 유지하며 추가 «사용 중» 표시를 제거했습니다.
- 배터리 세부 정보, 전력 흐름의 넓은 띠 연결부, 간체／번체 병음 및 a/A 입력 표시를 개선했습니다.

이 개인 Fork는 앞으로 `kains2866/status-trio`에서 업데이트를 받습니다.
