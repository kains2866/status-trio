# Персональная версия %VERSION% (сборка %BUILD%)

### Улучшения персональной панели

- Единые тонкие системные ползунки и выровненные строки устройств для яркости, выходной громкости и усиления микрофона.
- Отдельные уровень и отключение звука для поддерживаемых устройств. Нажатие значка слева выбирает системный выход или вход.
- Длинные названия полностью раскрываются с анимацией при наведении. Списки более чем из трёх устройств используют боковую панель.
- Единые боковые панели при наведении с нейтрально-серой подсветкой. Сведения о Wi-Fi остаются свёрнутыми до запроса.
- При переключении микрофона порядок устройств сохраняется; дополнительная метка «Используется» удалена.
- Улучшены сведения о батарее, стыки широких полос потока энергии и индикаторы упрощённого/традиционного пиньиня и a/A.

Этот персональный форк будет получать обновления из `kains2866/status-trio`.
